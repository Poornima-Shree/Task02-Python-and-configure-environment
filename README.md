# Task 02: Install Python and Configure Environment

## 📌 Project Overview

This project is part of my Data Science Internship (Level 1).

The objective of this task is to install Python, configure the development environment, load a public dataset, perform basic data analysis, and create visualizations using Python libraries.

For this project, I used the Iris flower dataset to explore and understand different flower species through their measurements.

## 📊 Dataset Information

**Dataset Name:** Iris Dataset

**Dataset Source:** UCI Machine Learning Repository

**Dataset Link:** https://archive.ics.uci.edu/dataset/53/iris

**Dataset Loading Method:** Scikit-learn (`load_iris`)

The dataset contains:
- 150 flower records
- 3 flower species:
  - Setosa
  - Versicolor
  - Virginica
- 4 measurement features:
  - Sepal length
  - Sepal width
  - Petal length
  - Petal width

Note: I used the Iris dataset bundled with Scikit-learn, which contains two corrected data points compared with the original UCI dataset.

## ⚙️ Project Implementation

The following steps were completed:

1. Installed Python and configured the environment.
2. Installed the required Python libraries.
3. Created a Jupyter Notebook in VS Code.
4. Loaded the Iris dataset using Scikit-learn.
5. Converted the dataset into a Pandas DataFrame.
6. Explored the dataset using `head()`, `info()` and `shape`.
7. Checked missing values.
8. Calculated average measurements for each flower species.
9. Created visualizations using Matplotlib and Seaborn.
10. Analyzed the results and documented the findings.

## 📈 Visualizations

### 1. Petal Length vs Petal Width

A scatter plot was created to compare petal length and petal width across the three Iris species.

### 2. Average Petal Length by Species

A bar chart was created to compare the average petal length of the three flower species.

## 🔍 Key Findings

- The dataset contains 150 flower records.
- Each flower species has 50 records.
- The dataset contains no missing values.
- Iris virginica has the highest average petal length.
- Iris setosa has the lowest average petal length.
- Petal measurements help distinguish the three flower species.
